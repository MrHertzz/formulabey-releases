# FormulaBey Companion

Sim racing companion app for Windows: overlays, Pit Wall, telemetry analysis and a remote engineer
for Assetto Corsa Competizione, Assetto Corsa, AC EVO, AC Rally, iRacing, Le Mans Ultimate and F1 25.

This repository only hosts the installers. The app finds new versions here by itself and asks before
downloading them.

**Download:** [latest release](https://github.com/MrHertzz/formulabey-releases/releases/latest) →
`FormulaBey-Companion-Setup-<version>.exe`
