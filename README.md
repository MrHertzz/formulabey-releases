# Simwall

**Simwall** (by FormulaBey) is a sim racing companion app for Windows: overlays, a layout manager,
Pit Wall, driver displays, telemetry analysis, friends and a remote engineer for Assetto Corsa
Competizione, Assetto Corsa, AC EVO, AC Rally, iRacing, Le Mans Ultimate and F1 25.
Up to version 2.2.13 it was called FormulaBey Companion.

This repository only hosts the installers. The app finds new versions here by itself and asks before
downloading them.

**Download:** [latest release](https://github.com/MrHertzz/formulabey-releases/releases/latest) →
`Simwall-Setup-<version>.exe`
